2. #94/95.11, 3. #94/95.14 — asserted only a negative, trivially true where the mechanism is absent

6. #107 — `macos || wsl` could not distinguish the branch it named from the one above it
7. Codex's own `T12` — shellcheck byte-stability verifies nothing in a doc-only change
8. `framework_init`'s `chmod 700` — would have made *every* reject-case in the #100 suite pass vacuously
9. `$out != *"SUCCESS"*` — satisfied by the very message proving the code right (`"Refusing to report SUCCESS on a downgrade."`)
10. `rc=$(_run_sweep …)` — subshell meant two tests were green against empty strings

**None was catchable by `bash -n` or `shellcheck`.** Every one was found by running an assertion against a tree where the mechanism was absent, or by reading failure *output* instead of a verdict. Seven were found by the teammates themselves, in their own code, unprompted.
